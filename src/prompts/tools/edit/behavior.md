For coordinated changes in one file, use edits to apply disjoint replacements atomically against the original snapshot. Do not chain replacements through one another within a batch. Exact matching is the default; match_mode="trailing-whitespace" is an explicit, full-line recovery option that never ignores indentation or changes unrelated lines. An overlap, missing match, or ambiguous match rejects the entire batch. A hint that replacement text is already present is not a success; re-read before deciding what remains.
