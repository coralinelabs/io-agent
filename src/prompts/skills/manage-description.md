Inspect or modify a reusable skill package in the configured userspace skills directory. Inspect first, then apply using that exact revision (null means a new empty package). Every operation replaces one entire UTF-8 file, or deletes it when content is null; read existing instructions before rewriting them. Paths are relative to the named package, not the workspace. Include a valid SKILL.md and all supporting files needed by the procedure. The complete proposed package is validated before writing. Failed writes attempt guarded rollback and report uncertain effects; this is not a crash-atomic multi-file transaction. This tool does not run skill scripts, modify project/plugin skill sources, or grant permissions to the resulting skill. Maximum 64 files and 4 MiB per package. Use ordinary file tools for larger or binary edits.
